# 付録C インターネット上の情報源（Resources on the Internet）（ドラフト）

本ファイルは、[FreeBSD Handbook（英語）](https://docs.freebsd.org/en/books/handbook/eresources/)の「Appendix C. Resources on the Internet」（既存 TOC ID C）を、[freebsd/freebsd-doc](https://github.com/freebsd/freebsd-doc) の固定コミット `a39743a3b0535f4498735119317889ea2bdfeb28`（`documentation/content/en/books/handbook/eresources/_index.adoc`）に基づいて日本語へ意訳したものです。

> **訳注**: 原文の AsciiDoc フロントマターおよび文書属性・共有ファイルの `include::` は翻訳対象外とし、本文の節のみを意訳しています。本ファイルは翻訳作業中のドラフトです。

FreeBSD の開発は非常に速いペースで進んでいるため、最新動向を把握する手段として印刷媒体を使うのは現実的ではありません。
開発状況を追うには、印刷物に代わる電子的な情報源が最も適しています。

FreeBSD ユーザーコミュニティは充実した技術サポートを提供しており、なかでもフォーラム、チャット、電子メールが最も広く使われ、かつ効果的な連絡手段となっています。

以下に、特に重要な連絡先や情報源をまとめます。
より最新の情報は、[コミュニティ Wiki（Community wiki area）](https://wiki.freebsd.org/Community)に掲載されている場合があります。

不要になった情報源や、まだ以下に掲載されていない情報源がある場合は、[FreeBSD ドキュメンテーションプロジェクト・メーリングリスト（freebsd-doc）](https://lists.FreeBSD.org/subscription/freebsd-doc)までお知らせください。

## Web サイト（Websites）

* [FreeBSD Forums](https://forums.FreeBSD.org/) は、FreeBSD に関する質問や技術的な議論を行うための Web ベースのディスカッションフォーラムです。
* [FreeBSD Wiki](https://wiki.FreeBSD.org/) には、まだ FreeBSD ハンドブックに収録されていないさまざまな情報が掲載されています。
* [Documentation Portal](https://docs.FreeBSD.org/) では、FreeBSD ハンドブックだけでなく、40 を超えるブックや記事が提供されています。
* [FreeBSD Journal](https://freebsdfoundation.org/our-work/journal/browser-based-edition/) は、[The FreeBSD Foundation](https://freebsdfoundation.org) が発行する、プロによる編集を経た無料の隔月刊技術誌です。
* [BSDConferences YouTube Channel](http://www.youtube.com/bsdconferences) では、世界各地の BSD カンファレンスで収録された高品質な動画コレクションが公開されています。中心的な開発者が FreeBSD の新しい取り組みについて発表する様子を視聴するのに最適です。
* [FreeBSD Status Reports](https://www.freebsd.org/status/) は 3 か月ごとに公開され、FreeBSD 開発の進捗状況を追跡できます。
* r/freebsd には、[FreeBSD に特化した Reddit グループ](https://www.reddit.com/r/freebsd/)があります。
* システム管理者向けの Stack Exchange サービスである [Super User](https://superuser.com/questions/tagged/freebsd) および [Server Fault](https://serverfault.com/questions/tagged/freebsd)。
* [FreeBSD Discord サーバー](https://wiki.freebsd.org/Discord)は、コミュニケーションとコミュニティ形成のためのサービスです。FreeBSD コミュニティのメンバー同士が交流したり、サポートを受けたり提供したり、学習・貢献・共同作業を行ったり、FreeBSD に関する最新情報を把握したりできます。
* [IRC チャネル](https://wiki.freebsd.org/IRC/Channels)は、広く実装され技術的に成熟した、オープン標準のテキストチャットです。
