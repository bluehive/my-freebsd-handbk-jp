FreeBSD の開発は非常に速いペースで進んでいるため、最新動向を把握する手段として印刷媒体を使うのは現実的ではありません。
開発状況を追うには、印刷物に代わる電子的な情報源が最も適しています。

FreeBSD ユーザーコミュニティは充実した技術サポートを提供しており、なかでもフォーラム、チャット、電子メールが最も広く使われ、かつ効果的な連絡手段となっています。

以下に、特に重要な連絡先や情報源をまとめます。
より最新の情報は、[コミュニティ Wiki（Community wiki area）](https://wiki.freebsd.org/Community)に掲載されている場合があります。

不要になった情報源や、まだ以下に掲載されていない情報源がある場合は、[FreeBSD ドキュメンテーションプロジェクト・メーリングリスト（freebsd-doc）](https://lists.FreeBSD.org/subscription/freebsd-doc)までお知らせください。

<a id="eresources-www"></a>
## Web サイト（Websites）

* [FreeBSD Forums](https://forums.FreeBSD.org/) は、FreeBSD に関する質問や技術的な議論を行うための Web ベースのディスカッションフォーラムです。
* [FreeBSD Wiki](https://wiki.FreeBSD.org/) には、まだ FreeBSD ハンドブックに収録されていないさまざまな情報が掲載されています。
* [Documentation Portal](https://docs.FreeBSD.org/) では、FreeBSD ハンドブックだけでなく、40 を超えるブックや記事が提供されています。
* [FreeBSD Journal](https://freebsdfoundation.org/our-work/journal/browser-based-edition/) は、[The FreeBSD Foundation](https://freebsdfoundation.org) が発行する、プロによる編集を経た無料の隔月刊技術誌です。
* [BSDConferences YouTube Channel](http://www.youtube.com/bsdconferences) では、世界各地の BSD カンファレンスで収録された高品質な動画コレクションが公開されています。中心的な開発者が FreeBSD の新しい取り組みについて発表する様子を視聴するのに最適です。
* [FreeBSD Status Reports](https://www.freebsd.org/status/) は 3 か月ごとに公開され、FreeBSD 開発の進捗状況を追跡できます。
* r/freebsd には、[FreeBSD に特化した Reddit グループ](https://www.reddit.com/r/freebsd/)があります。
* システム管理者向けの Stack Exchange サービスである [Super User](https://superuser.com/questions/tagged/freebsd) および [Server Fault](https://serverfault.com/questions/tagged/freebsd)。
* [FreeBSD Discord サーバー](https://wiki.freebsd.org/Discord)は、コミュニケーションとコミュニティ形成のためのサービスです。FreeBSD コミュニティのメンバー同士が交流したり、サポートを受けたり提供したり、学習・貢献・共同作業を行ったり、FreeBSD に関する最新情報を把握したりできます。
* [IRC チャネル](https://wiki.freebsd.org/IRC/Channels)は、広く実装され技術的に成熟した、オープン標準のテキストチャットです。

<a id="eresources-mail"></a>
## メーリングリスト（Mailing Lists）

メーリングリストは、FreeBSD に関心の高い読者層に向けて質問を投げかけたり、技術的な議論を始めたりするための最も直接的な手段です。
FreeBSD のさまざまなトピックに応じた多種多様なリストが用意されています。
質問内容に最も適したメーリングリストへ送ることで、より速く正確な回答を得られる可能性が確実に高まります。

技術系のリストでは、スレッドの内容も技術的な議論にとどめるべきです。

FreeBSD のすべてのユーザーおよび開発者は、[FreeBSD アナウンスメント・メーリングリスト（freebsd-announce）](https://lists.FreeBSD.org/subscription/freebsd-announce)を購読しておくことを推奨します。

> **注**: FreeBSD メーリングリストの動作をテストしたい場合は、[FreeBSD テスト・メーリングリスト（freebsd-test）](https://lists.FreeBSD.org/subscription/freebsd-test)宛てに送信してください。他のメーリングリストへテストメッセージを送信しないでください。

どのリストに質問を投稿すべきか迷った場合は、[How to get best results from the FreeBSD-questions mailing list](https://docs.freebsd.org/en/articles/freebsd-questions/) を参照してください。

どのメーリングリストへ投稿する場合も、事前に次の点を行ってください。

* 何度も繰り返される議論を避けるコツなど、メーリングリストを上手に活用する方法を学ぶため、[Mailing List Frequently Asked Questions](https://docs.freebsd.org/en/articles/mailing-list-faq/)（FAQ）文書を読む。
* すでに同じ内容が投稿されていないか確認するため、アーカイブを検索する。

アーカイブ検索用のインターフェースには、次のようなものがあります。

* [https://lists.freebsd.org/search](https://lists.freebsd.org/search)（FreeBSD 提供、実験的）
* [https://www.freebsd.org/search/](https://www.freebsd.org/search/)（DuckDuckGo）

これは同時に、FreeBSD のメーリングリストに送信されたメッセージは永久にアーカイブされることも意味します。
プライバシー保護が気になる場合は、使い捨ての副メールアドレスを使い、公開しても問題ない情報だけを投稿することを検討してください。

FreeBSD が提供するアーカイブには、次の特徴があります。

* リンクをクリッカブルなリンクとしては表示しない
* インライン画像を表示しない
* HTML メールの HTML コンテンツを表示しない

FreeBSD の公開メーリングリスト一覧は、[https://lists.freebsd.org](https://lists.freebsd.org) で確認できます。

<a id="eresources-subscribe"></a>
### 購読・購読解除の方法（How to Subscribe or Unsubscribe）

[https://lists.freebsd.org](https://lists.freebsd.org) でリスト名をクリックすると、そのリストの各種オプションが表示されます。

購読したあとに投稿するには、`listname@FreeBSD.org` 宛てにメールを送信します。
送信されたメッセージはリストのメンバー全員に再配信されます。

<a id="eresources-charters"></a>
### メーリングリストの基本ルール（Lists Basic Rules）

**すべて**の FreeBSD メーリングリストには、利用者全員が守るべき基本ルールがあります。
これらのガイドラインに従わなかった場合、FreeBSD Postmaster（[postmaster@FreeBSD.org](mailto:postmaster@FreeBSD.org)）から 2 回の書面による警告が送られ、3 回目の違反で投稿者はすべての FreeBSD メーリングリストから削除され、以降の投稿もフィルタリングで遮断されます。
このようなルールや措置を設けざるを得ないのは遺憾ですが、今日のインターネットはかなり厳しい環境になっており、その仕組みがいかに繊細であるかを理解していない人が少なくありません。

利用にあたっての基本ルールは次のとおりです。

* 投稿の話題は、投稿先リストの基本的な趣旨に沿ったものにしてください。技術的な話題を扱うリストであれば、投稿内容も技術的な議論にとどめる必要があります。無関係な雑談の継続やフレーミング（罵り合い）は、参加している全員にとってメーリングリストの価値を下げるだけであり、容認されません。特定のテーマにとらわれない自由な議論には、[FreeBSD チャット・メーリングリスト（freebsd-chat）](https://lists.FreeBSD.org/subscription/freebsd-chat)が自由に利用できますので、そちらを使ってください。
* 2 つを超えるメーリングリストへの同時投稿は行わないでください。2 つのリストへ投稿してよいのも、両方のリストに投稿する明確かつ明白な必要がある場合に限られます。多くのリストでは購読者が大きく重複しているため、ごく特殊な組み合わせ（たとえば「-stable と -scsi」など）を除き、一度に 1 つを超えるリストへ投稿する理由はほとんどありません。`Cc` 行に複数のメーリングリストが含まれたメッセージを受け取った場合は、返信する前に `Cc` 行を整理してください。**元の投稿者が誰であったとしても、返信した本人がクロスポストの責任を負います。**
* 議論の文脈における個人攻撃や暴言は禁止されています。これはユーザーにも開発者にも等しく適用されます。許可を得ておらず得られる見込みもない私信の引用や再投稿といった、ネチケットに対する著しい違反は、明確な罰則の対象とはされていませんが強く忌避されます。
* FreeBSD に関係のない製品やサービスの宣伝は固く禁止されており、スパムによる宣伝行為であることが明らかな場合は即座に利用禁止措置が取られます。

<a id="eresources-mailfiltering"></a>
### メーリングリストでのフィルタリング（Filtering on the Mailing Lists）

FreeBSD のメーリングリストでは、スパム、ウイルス、その他の不要なメールが配信されるのを防ぐため、複数の方法でフィルタリングを行っています。
この節で説明するフィルタリング処理は、メーリングリストを保護するために実施されている対策のすべてを網羅しているわけではありません。

メーリングリストでは、特定の種類の添付ファイルのみが許可されています。
以下の一覧に含まれない MIME コンテンツタイプの添付ファイルは、メールがメーリングリストに配信される前にすべて取り除かれます。

* `application/octet-stream`
* `application/pdf`
* `application/pgp-signature`
* `application/x-pkcs7-signature`
* `message/rfc822`
* `multipart/alternative`
* `multipart/related`
* `multipart/signed`
* `text/html`
* `text/plain`
* `text/x-diff`
* `text/x-patch`

> **注**: 一部のメーリングリストでは上記以外の MIME コンテンツタイプの添付ファイルが許可されている場合もありますが、ほとんどのメーリングリストにはこの一覧が適用されます。

マルチパートメッセージに `text/plain` パートと `text/html` パートの両方が含まれている場合、次のように処理されます。

* 受信者には両方のパートが届きます。
* `lists.freebsd.org` のアーカイブでは `text/plain` が表示され、元のテキスト（各パートに生 HTML を含むソース）を表示するオプションが提供されます。

`text/html` に `text/plain` が添付されていない場合は、次のように処理されます。

* HTML からプレーンテキストへの変換が行われます。
